# برنامه مرکزی شیفت ناظرین خط و ابنیه

این نسخه برای چندین گوشی طراحی شده است. همه کاربران از یک سرور مرکزی اطلاعات می‌گیرند و مدیر می‌تواند فایل Excel سال جدید را یک‌بار آپلود کند.

## امکانات
- داشبورد شیفت امروز
- جستجوی تاریخ شمسی؛ ورود ۸ رقم مثل `۱۴۰۵۰۵۲۷` کافی است و `/` لازم نیست
- جدول کامل برنامه و فیلتر نام ناظر
- PWA قابل نصب روی Android
- به‌روزرسانی مرکزی Excel برای همه کاربران
- رمز مدیر برای آپلود و بازیابی
- ذخیره پایدار اطلاعات با `DATA_DIR` (مناسب Railway Volume)
- در صورت Restart یا Deploy، اطلاعات از Volume باقی می‌ماند

## متغیرهای محیطی
`ADMIN_PASSWORD` = رمز مدیر
`DATA_DIR` = مسیر Volume، در Railway پیشنهاد می‌شود `/data`

## اجرای محلی
```bash
npm install
ADMIN_PASSWORD="رمز-قوی" DATA_DIR="./storage" npm start
```
سپس `http://localhost:3000`

## انتشار
این پروژه یک Node.js/Express web service است و باید روی سرویسی اجرا شود که HTTPS و storage پایدار ارائه کند.
برای Railway:
1. Repository را از GitHub وصل کنید.
2. Variable با نام `ADMIN_PASSWORD` بسازید.
3. یک Volume بسازید و Mount Path را `/data` قرار دهید.
4. Variable با نام `DATA_DIR` و مقدار `/data` بسازید.
5. Domain عمومی HTTPS بسازید.
6. برنامه را باز کنید.

## ساختار Excel

تاریخ، روز هفته، کارفرما روز، کارفرما شب، پیمانکار عصر، پیمانکار شب.

## نکته امنیتی
رمز مدیر را داخل GitHub یا فایل‌های پروژه قرار ندهید. فقط در Environment Variables سرویس قرار دهید.
